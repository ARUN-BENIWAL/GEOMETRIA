# GEOMETRIA
GEOMETRIA is an interactive web application that visually demonstrates 2D and 3D transformations using real-time controls and matrix-based operations. It allows users to explore translation, rotation, scaling, and more through an intuitive visual interface, making complex computer graphics concepts easy to understand.



# 🌌 GEOMETRIA – The Art of Transformation

GEOMETRIA is an interactive web-based application that visually demonstrates the core concepts of **2D and 3D geometric transformations** in a simple, intuitive, and engaging way.

It transforms complex mathematical ideas into **real-time visual experiences**, helping users understand how transformations work in computer graphics.

## 🚀 Live Demo

👉 https://geometria-six.vercel.app/

---

## 🎯 Features

### 🔷 2D Transformations

* Translation (X, Y movement)
* Rotation (angle-based)
* Scaling (uniform & non-uniform)
* Reflection (X-axis, Y-axis)
* Shearing (X & Y axis)
* Transformation matrices displayed

---

### 🔶 3D Transformations

* 3D Translation
* 3D Rotation (X, Y, Z axes)
* 3D Scaling
* Wireframe object visualization (Cube)
* Perspective projection
* Axis visualization (X, Y, Z)

---

### 🧪 Visual Lab (Interactive Playground)

* Real-time transformation using sliders
* Switch between 2D and 3D modes
* Before vs After visualization
* Composite transformations (chaining multiple operations)
* Matrix-based transformation logic

---

## 🛠️ Tech Stack
